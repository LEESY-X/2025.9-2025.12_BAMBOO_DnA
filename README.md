# BAMBOO DnA · 주가와 뉴스 제목 분석

삼성전자, SK하이닉스, LG에너지솔루션을 대상으로 뉴스 제목의 감성 점수와 주가 등락률의 상관관계를 분석했습니다. 분석 기간은 2024년 1월 1일부터 2025년 11월 15일까지입니다.

## 분석 순서

1. KRX 주가와 네이버 증권 뉴스 제목을 수집합니다.
2. 뉴스 제목에 감성 점수를 부여하고 일별 주가와 결합합니다.
3. ADF 검정과 피어슨 상관분석을 수행합니다.

[Code](Code)에 수집·전처리·분석 코드가 있고, [Data](Data)는 기업별로 구성돼 있습니다.

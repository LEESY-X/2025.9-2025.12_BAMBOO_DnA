# 뉴스의 긍정/부정 성향과 주가 등락률의 상관성 분석 및 제언

### **Project Summary**

- **프로젝트 개요**
    
    **주제**: 뉴스 제목의 성향(긍정/부정)과 시가총액 상위 기업 주가의 상관성 분석
    
    **분석 배경**: 주식 뉴스는 주식 시장에 영향을 미치는 핵심 요인 임을 통계적으로 증명하기 위해서 본 프로젝트를 진행했다.
    
    **분석 대상**: 삼성전자, SK하이닉스, LG에너지솔루션 (KOSPI 시가총액 상위 3개 회사) 
    
    **분석 데이터 기간**: 2024.01.01 ~ 2025.11.15 
    
    **사용 데이터**: KRX 주가 데이터, 네이버 증권 뉴스 제목
    
- **주요 기술**
    
    **데이터 수집**: Crawling 
    
    **데이터 전처리**: Text Mining (긍정/부정 성향 점수화) 
    
    **데이터 시각화**: 시계열 그래프, 워드 클라우드 
    
    **데이터 검정**: ADF Test (정상성 검증), Pearson Correlation (상관 분석)
    
- **분석 결과 및 제언**
    
    3사 모두 통계적으로 유의미한 양의 상관관계 확인하였다.
    
    {삼성전자 (r=0.333), LG엔솔 (r=0.320), SK하이닉스 (r=0.196)}
    
    특정 기업에 관한 긍정/부정 뉴스가 많아질 것으로 예상될 때 해당 기업의 주식이 상승/하락할 가능성이 통계적으로 유의하다는 점을 고려하여 투자하는 것이 효과적일 것이다.
